# Go2 Route Locomotion — project page

Static project page for a reinforcement-learning locomotion controller for the Unitree Go2 on an inspection route
(stairs, kerbs, ramps, rough ground, thresholds), guided by an emulated L1 LiDAR elevation map: trained in Isaac Lab,
validated sim-to-sim in MuJoCo through Unitree SDK2, a C++ controller and ROS 2.

Page: https://747235257qqmdc-sys.github.io/go2-route-locomotion/

This repository holds only the page (`index.html`) and its media (`media/`, MuJoCo replays and figures). The code
repository is private and available on request.
